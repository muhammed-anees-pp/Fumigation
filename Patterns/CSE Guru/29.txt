Ans:

#include <stdio.h>
int main(){
	int i,j,row=5;
	for(i=1;i<=row;i++){
		for(j=1;j<=i;j++){
			printf("%d ",j%2);
		}
		printf("\n");
	}

	return 0;
}


Working:

j%2

Iteration 1 (i=1)
j=1%2=1 (1)

Iteration 2 (i=2)
j=1,2%2=0 (10)

Iteration 3 (i=3)
j=1,2,3%2=1 (101)
