Q13:

1 2 3 4 5
1 2 3 4
1 2 3
1 2
1

Ans:

#include <stdio.h>
int main(){
	int i,j,row=5;
	for(i=row;i>=1;i--){
		for(j=1;j<=i;j++){
			printf("%d ",j);
		}
		printf("\n");
	}
	

	return 0;
}


Working:

Iteration 1 (i=5)
j=1,2,3,4,5

Iteration 2 (i=4)
j=1,2,3,4

Iteration 3 (i=3)
j=1,2,3

Iteration 4 (i=2)
j=1,2

Iteration 5 (i=1)
j=1
