# Programming Practice and Challenges

This repository contains a collection of programming exercises, challenges, pattern programs, array problems, and Java-specific concepts. It is organized into various sections to systematically learn and practice programming.

## Repository Structure

### 📁 01. 3 hours challenge
Contains projects and programs designed to be completed within a 3-hour timeframe.
- `ATM_Machine`: Implementation of an ATM Machine simulation.
- `programs`: Various other practice programs.

### 📁 02. 100K Challenge
A series of structured programming challenges, divided into distinct parts/days (01 to 09) and a specific section for programs from parts 02 to 06.

### 📁 03. Patterns
A collection of pattern printing programs (e.g., star patterns, number patterns) categorized by learning sources:
- `CSE Guru`
- `CodeCoders`
- `Jenny's lecture`
- `MySirG`
- `Tech Doctor Malayalam`

### 📁 04. Array
Problems and concepts focused on Arrays, categorized by learning sources:
- `CSE Guru`
- `CodeCoders`
- `Tech Doctor Malayalam`

### 📁 05. Java-programs
Programs specifically focused on Object-Oriented Programming (OOP) concepts in Java:
- `Encapsulation`
- `Inheritance`
- `Polymorphism`
- `super` (The `super` keyword in Java)

### 📁 06. Notes
Contains theoretical notes and explanations.
- `Jenny's Lecture`: Notes taken from Jenny's lectures.
